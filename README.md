# Krittika Nandy · Portfolio

An animated, black-and-red personal portfolio with a Node.js backend for contact messages and live counters.

**🔗 Live site:** https://krittikanandy06-ctrl.github.io/krittika-portfolio/

## About

Full-Stack Web Developer and B.Tech CSE (AI & ML) student at ABES Engineering College, open to internships.

## ✨ Features

- Animated hero section with my photo
- Project case-study pop-ups
- Certificate filter and viewer
- Journey timeline
- Hidden terminal (press `~`)
- Simba the dog
- Contact form
- Visitor counter

## 🛠 Tech stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express, MongoDB Atlas (Mongoose)
- **Hosting:** GitHub Pages + Render

## 📁 Project structure

```
krittika-portfolio/
├── index.html    # page content
├── css/          # styles and animations
├── js/           # interactivity, terminal, forms
├── images/       # photo, project and certificate images
├── resume/       # downloadable resume (PDF)
└── backend/      # Express API (contact, counters)
```

## 🚀 Run locally

**Frontend:** open `index.html` with the VS Code Live Server extension.

**Backend:**

```bash
cd backend
npm install
cp .env.example .env   # then fill in your own values
npm run dev
```
